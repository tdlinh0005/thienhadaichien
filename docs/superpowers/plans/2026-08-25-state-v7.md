# State v7 Implementation Plan — Kinh tế thật · Địa hình · Tình báo lương · Ba chính thể

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Đưa bốn cơ chế có nguồn tư liệu nhưng bản dựng v6 còn thiếu vào game: bộ ba thị trường + ngân hàng, chiến đấu theo địa hình, lương gián điệp/phản bội, ba chính thể liên minh — tất cả trên state v7.

**Architecture:** Giữ nguyên tắc "một bộ luật duy nhất": luật mới nằm trong `js/*.js` (server `eval` qua `server/rules.js`), thế giới chung đi qua `G.HOOK`, server quyết định. State nâng additive v6→v7 (chỉ gắn default). Chợ dùng bảng SQLite chung `cho`; phiếu liên minh dùng `lm_phieu`+`lm_phieu_chi_tiet`.

**Tech Stack:** Node ≥22.5 (`node:http`, `node:sqlite`, `node:crypto`) — không thêm dependency. Vanilla JS client.

## Global Constraints

- Không thêm package nào vào `package.json` (`dependencies: {}` phải giữ nguyên).
- Mọi con số neo lấy từ spec `docs/superpowers/specs/2026-08-25-kinh-te-chinh-the-design.md`: KL=1, TA=2, NL=4, TP=1 GL; thuế siêu thị 10%, Tự Do 5%; giao hàng 6h = 21.600 giây; lãi ngân hàng dải [0.0007 … 0.02]/ngày; lương gián điệp NL/giờ; phiếu hạn 24h; bầu chủ 14 ngày; đại biểu top 5.
- Nhãn `[XÁC NHẬN]` / `[TÁI DỰNG]` phải xuất hiện trong comment cạnh mọi hằng số cân bằng mới.
- Code style: `'use strict'`, `var G = window.G = window.G || {}`, function declaration kiểu hiện có, comment tiếng Việt.
- Test chạy bằng `node tools/smoke.js` và `node tools/test-server.js` (khuôn `ktra(dk, ten)`); không framework mới.
- Sau mỗi Task: `npm test` phải xanh rồi mới commit.
- Server vẫn là bên duy nhất quyết định: hành động luật qua `G.HANHDONG`, dữ liệu chéo đế quốc qua phương thức `TheGioi.*` + API riêng, không bao giờ tin client.
- Solo (không `G.HOOK`) và multiplayer phải cùng chạy được mọi tính năng; solo dùng NPC thay người thật ở thị trường.
